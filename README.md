# Rapt0r

**Rapt0r** is a high-throughput, header-only C++20 binary serialization library designed for game engines and performance-critical systems.

The library is under construction, I plan to use this in the [Surge Engine](https://github.com/ridhwandll/Surge_Expired) as a unified way of binary and runtime serialization! Also this found this as a nice learning project.
